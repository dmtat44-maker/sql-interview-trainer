# Черновик privacy policy для SQL Interview Trainer

Приложение SQL Interview Trainer предназначено для подготовки к собеседованиям по SQL.

## Какие данные собираются

Текущая версия приложения не отправляет личные данные на сервер.

Приложение может сохранять на устройстве пользователя:

- прогресс прохождения карточек;
- статистику правильных и неправильных ответов;
- вопросы, добавленные пользователем в локальную базу.

Эти данные хранятся локально на устройстве через механизм браузерного/встроенного хранилища WebView.

## Передача данных третьим лицам

Текущая версия приложения не передаёт данные третьим лицам.

## Интернет-доступ

В Android-проекте может присутствовать разрешение INTERNET, добавленное Capacitor по умолчанию. В текущей версии приложение работает локально и не требует аккаунта.

## Удаление данных

Пользователь может сбросить прогресс внутри приложения. При удалении приложения локальные данные также могут быть удалены системой.

## Контакты

Заменить на контакт разработчика перед публикацией.
